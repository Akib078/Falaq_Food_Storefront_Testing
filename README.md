## 📌 Project Overview

A comprehensive **Software Quality Assurance (SQA) project** for testing the Falaq Food e-commerce storefront through both **Manual Testing** and **Automation Testing**.

The project covers functional validation of core e-commerce workflows, UI and usability testing, defect management, and automated regression testing using **Selenium WebDriver, Java, TestNG, Maven, and Page Object Model (POM)**.

**Application:** Falaq Food E-commerce Storefront
**Testing Approach:** Manual + Automation
**Automation Framework:** Selenium WebDriver + Java + TestNG + POM
**Defect Tracking:** Jira
**Build Tool:** Maven

---

## 🎯 Objectives

* Validate critical e-commerce functionalities and user workflows.
* Identify functional, UI, usability, and workflow-related defects.
* Ensure the application meets expected business requirements.
* Create structured and professional QA documentation.
* Automate repetitive regression test scenarios.
* Build a maintainable Selenium automation framework using POM.
* Demonstrate an end-to-end SQA workflow from test planning to defect reporting and automation.

## 🏗️ Automation Framework

Developed a modular **Selenium-Java-TestNG automation framework** following the **Page Object Model (POM)** design pattern.

The framework was designed to provide:

* Reusable page components
* Maintainable locators
* Reusable utility methods
* Explicit waits
* TestNG-based test execution
* Assertions for validation
* Structured test organization
* Scalable regression automation

## ⚙️ Automated Workflows

Automated critical e-commerce workflows including:

1. Launch storefront
2. Navigate through product categories
3. Search for products
4. Apply product filters
5. Select products
6. Add products to cart
7. Update cart quantity
8. Select shipping option
9. Navigate to checkout
10. Validate checkout form
11. Complete checkout/order workflow

The automation suite focuses on repetitive and critical regression scenarios to reduce manual execution effort.
